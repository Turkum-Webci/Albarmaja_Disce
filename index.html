    Bazı Temel Bilgiler:
    #:eğer kullanılcak şey id ise bunun ile başlanılır
    .:eğer class kullanılıyorsa bunun ile başlanılır

    CSS'ten Bazı Kodlar:
  • background-color: ;

    • Bu Kod İle Bir tane renk veririz.Örneğin:
    #div1{
    background-color: red;
    }

  • width: ;

    • Bu Kod İle element (HTML kodu/tagi)'in genişliğini ayarlarız.Örneğin:
    #div1{
    width: 100px;
    }

  • height: ;

    • Bu Kod İle element (HTML kodu/tagi)'in uzunluğunu ayarlarız.Örneğin:
    #div1{
    height: 100px;
    }

  • color: ;

    • Bu Kod İle yazı rengini ayarlarız.Örneğin:
    #div1{
    color: blue;
    }

  • border-radius: ;

    • Bu Kod İle element'in (HTML kodu/tagi)'in yumuşaklık(yuvarlaklığını) ayarlarız.Örneğin:
    #div1{
    border-radius: 20px;

    SetInterval ve SetTimeout:

  • SetInterval(function ?(){}, ?);

    • SetInterval sayesinde her belirlenen vakitte bir olayın tekrar tekrar tetiklenmesi gerçekleşir.


    Açıklama:SetInterval(function ?(){}, ?) burda 2. ? yerine orda olucak saniye çarpı 1000 yazılır yani 5 saniye olması istenirse oraya 5000 yazılır.

    Örneğin:

    var a = 0;
    SetInterval(function A(){
    a += 1;
    alert(a);
    }, 1000);

    her saniye 1-2-3 diye sayar.

  • SetTimeout(function ?(){}, ?);

    • SetTimeout sayesinde her belirlenen vakitte bir olayın tetiklenmesi gerçekleşir.Örneğin:

    var a = 0;
    SetTimeout(function A(){
    a += 1;
    alert(a);
    }, 1000);

    sadece birkez 1 saniyeliğine a'nın değeri söylenir.
