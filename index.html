    CSS Öğrenme

    Bazı Temel Bilgiler:
    #:eğer kullanılcak şey id ise bunun ile başlanılır
    .:eğer class kullanılıyorsa bunun ile başlanılır
    ; : bunun ile kod durdurulur
    {: ile yapılcak şey başlatılır id yada class'ın içinde olucak kodlar
    }: bunun ile kapatılır.

    CSS'ten Bazı Kodlar:
  • background-color: ;

    • Bu Kod İle Bir tane renk veririz.Örneğin:
    #div1{
    background-color: red;
    }

  • width: ;

    • Bu Kod İle element (HTML kodu/tagi)'in genişliğini ayarlarız.Örneğin:
    #div1{
    width: 100px;
    }

  • height: ;

    • Bu Kod İle element (HTML kodu/tagi)'in uzunluğunu ayarlarız.Örneğin:
    #div1{
    height: 100px;
    }

  • color: ;

    • Bu Kod İle yazı rengini ayarlarız.Örneğin:
    #div1{
    color: blue;
    }

  • border-radius: ;

    • Bu Kod İle element'in (HTML kodu/tagi)'in yumuşaklık(yuvarlaklığını) ayarlarız.Örneğin:
    #div1{
    border-radius: 20px;
    }
